# Prompt AI, Documentation (`/docs`)

This folder is the documentation hub for the project. It holds anything that is not code: architecture notes, design decisions, and reference material for contributors.

## Contents

This folder will grow over time. For now, the primary project documentation lives at the repository root:

- `ARCHITECTURE.md`, system design, service boundaries, and request flow
- `CONTRIBUTING.md`, how to contribute, branch and commit conventions
- `SECURITY.md`, how to report vulnerabilities
- `CHANGELOG.md`, a record of notable changes by version
- `WIKI.md`, index and starting point for deeper reference material

## Planned Additions

- `decisions/`, architecture decision records for significant technical choices, kept short and dated so contributors can see why a decision was made without digging through pull request history
- `guides/`, setup guides specific to each service, linked from each folder's own README
- `api-reference/`, generated or hand written reference for the `/api` and `/data` endpoints once they stabilize

## Status

Scaffolding stage. Content will be added as the project develops.
